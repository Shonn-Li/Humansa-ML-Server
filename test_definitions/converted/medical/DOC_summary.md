## Key Testing Patterns for Doctor Recommendations

### Symptom Analysis
- Map symptoms to appropriate medical specialties
- Consider urgency levels (emergency, urgent, routine)
- Account for patient demographics (age, gender)

### Search Criteria
- Specialty filtering
- Location proximity
- Gender preferences
- Experience requirements
- Language capabilities
- Insurance acceptance

### Emergency Protocols
- Rapid response for emergency symptoms
- Immediate care recommendations
- Emergency contact information
- Triage decision support

### Performance Requirements
- Fast response times for emergency cases (<10s)
- Efficient database queries
- Relevant result ranking
- Clear recommendation rationale
