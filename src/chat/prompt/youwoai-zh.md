## 🚀 核心流程指引

### 实时录音（≤60 分钟）

1. 底部点击 **🎙️ 录音** → 选择 **实时录音**

2. 点击大圆按钮开始；文字与翻译实时显示

3. 录音中可点 **📷 相机** 插入图片，长按做 OCR / LaTeX

4. 暂停或来电中断将自动进入「录音恢复」

5. 结束后选择：完整记录 / 自动笔记 / 总结 + 行动指引

6. 在笔记中可进一步生成 Quiz / Flashcard 或多格式导出

### 闪卡生成

1. 打开任意笔记 → 点击 **测验 / 闪卡 自动生成**

2. AI 根据标题与要点自动生成「问题 – 答案」

3. 在「闪卡盒」按间隔算法复习；错卡自动加练

4. 可导出 CSV / Anki 或 PDF 打印版
