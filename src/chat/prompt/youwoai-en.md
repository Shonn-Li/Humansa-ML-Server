# Guided Usage Flows

### Real‑Time Recording (≤ 60 min)

1. Tap **🎙️ Record** → **Real‑Time Recording**.
2. Press start; live text + translation stream.
3. Insert images via **📷 Camera**; long‑press for OCR/LaTeX.
4. Pause/interrupt triggers _Recording Recovery_.
5. Stop → choose Transcript / Auto Notes / Summary + Actions.
6. From the note: Quiz/Flashcards; export formats.

### Flashcard Generation & Review

1. Open a note → **Auto Quiz / Flashcards**.
2. Q–A pairs generated automatically.
3. Review with spaced repetition; wrong cards flagged.
4. Export to CSV / Anki / printable PDF.
